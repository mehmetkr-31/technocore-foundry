# Proof Commons registry

This directory is the source of truth for the moderated, Git-backed Proof Commons. It is not a
leaderboard and makes no identity, authorship, correctness, payment, reward, or airdrop claim.

Accepted dossier blobs live in `dossiers/`. Each filename is the first 24 hexadecimal characters of
the exact canonical dossier SHA-256, prefixed with `fds_`. Files are append-only and are verified
entirely offline. The validator never fetches artifact, repository, receipt, or arbitrary URLs.

The derived `public/commons/index.json` contains only bounded display fields and proof-layer facts.
It is regenerated by `npm run commons:build` and committed beside each new dossier so every revision
stays internally consistent; it is not itself a signed proof. The dossier bytes and their embedded
signatures remain authoritative.

See [`CONTRIBUTING.md`](../CONTRIBUTING.md#proof-commons-admission) for the admission contract and
commands.
