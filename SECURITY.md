# Security policy

Technocore Foundry is an independent community preview. Please do not include private keys,
passphrases, access tokens, unpublished receipts, or personal data in a vulnerability report.

Until a public security contact is selected, report issues privately to the repository owner using
the hosting or source-control account's private contact channel. Public disclosure and response
targets will be set before public access is enabled.

The current audit, enforced boundaries, regression commands, and residual risks are documented in
[`release/SECURITY_AUDIT.md`](release/SECURITY_AUDIT.md). A valid signature is not proof of truth,
authorship, identity, reward entitlement, or airdrop eligibility.
